# Feature Specification: 006 - Student Learning Board & Gamification

**Feature Directory**: `specs/006-student-learning-board`
**Created**: 2026-07-29
**Status**: Approved

## Requirements
- **FR-001**: `GET /api/learning-board` MUST return overall progress %, practice intensity logs, to-do list, and earned badges.
- **FR-002**: System MUST support full CRUD for `UserTodoList`.
- **FR-003**: System MUST automatically grant badges when milestone thresholds are reached.
